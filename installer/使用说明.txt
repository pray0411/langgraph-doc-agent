Pray 使用说明
============================================================

一、安装（推荐）
    方式 A（最简单）：双击 PraySetup.exe
    → 确认后自动安装，无需解压、无需管理员权限

    方式 B（绿色包）：解压后双击 install.bat
    → 自动安装到 %LOCALAPPDATA%\Programs\Pray（无需管理员权限）
    → 创建开始菜单与桌面快捷方式
    → 可在「设置 → 应用 → 已安装的应用」中正常卸载

    也可以不用安装：解压后直接双击 Pray.exe 作为绿色版运行。

二、首次使用：配置模型 API Key（只需一次）
    首次启动时，界面会自动弹出设置面板，提示填写 API Key：

        服务商：DeepSeek（默认）
        API Key：sk-你的密钥

    填写后点"保存"即可。Key 会保存在程序目录下的 .env 文件里，
    **下次启动无需重填**。

    其他服务商：设置面板里切换（OpenAI / 通义千问 / 智谱 / Kimi），
    填对应 Key；本地模型选 ollama（需先安装 Ollama）。

三、数据保存位置
    generated/   AI 生成的文件（代码、HTML 等）
    data/        会话记忆与会话历史
    logs/        运行日志与安全审计日志
    .env         你的模型配置（含密钥，注意不要外发）

四、自检与排查
    命令行执行：  Pray.exe --check
    会输出：页面状态、版本号、当前 provider、API Key 是否已配置、数据目录。
    若显示 "API Key=缺失"，说明还没配置（打开界面会有引导面板）。

五、更新
    启动时会查询 GitHub Releases，有新版本会弹窗提示下载地址（不会自动替换）。
    跳过检查：Pray.exe --no-update-check

六、功能提示
    - 直接提问即可：文档问答、联网搜索、写代码并运行验证都由 AI 自行决定调用哪些工具
    - 点击输入框左侧 📎 可上传文档（.md/.txt/.py 等），随后即可针对上传内容提问
    - 会话历史在左侧边栏，可回放、删除、导出

七、卸载
    方式 1：设置 → 应用 → 已安装的应用 → Pray → 卸载
    方式 2：运行程序目录下的 uninstall.bat
    默认保留 generated/ 与 data/（你的文件与记忆）；彻底清除可运行：
        uninstall.bat -PurgeData

八、安全提示
    本程序具备命令执行能力（执行前需要用户确认），定位是**单机个人开发辅助工具**，
    不是沙箱。请勿在共享或生产环境对外暴露本服务，详见项目 README 与 docs/安全模型.md。

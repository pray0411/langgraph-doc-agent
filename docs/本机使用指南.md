# Pray 本机使用指南（MCP 接入 + 桌面版）

> 场景：把 Pray 接进 Claude Desktop（或其他 MCP 客户端），以及把 Pray 跑成/打包成桌面应用。

## 〇、免账号快速验证（推荐先做这个）

**不需要 Claude 账号**，用项目自带的最小 MCP 客户端 `mcp_demo.py`：

```powershell
cd D:\dsh工作区\langgraph-doc-agent
python -X utf8 mcp_demo.py
```

连接成功会列出 pray 的 7 个工具；直接输入问题即可走 `ask` 工具问答
（含多轮记忆）；`/new` 新会话、`/mem` 看全局记忆、`/exit` 退出。
这是标准 MCP SDK 走 stdio 的真实链路，等价于任何 MCP 客户端能连 Pray。

## 一、MCP：接入 Claude Desktop

### 1. 安装 Claude Desktop（若未装）
- 官网下载：https://claude.ai/download（Windows 版）
- 安装完成后先登录一次（需 Claude 账号）

### 2. 放入 MCP 配置
项目里已生成好配置文件 `claude_desktop_config.example.json`（内含本机 python.exe 与
mcp_server.py 的绝对路径）。把它复制到 Claude 配置目录并改名：

```powershell
# 复制到 Claude Desktop 配置目录
New-Item -ItemType Directory -Force -Path "$env:APPDATA\Claude" | Out-Null
Copy-Item D:\dsh工作区\langgraph-doc-agent\claude_desktop_config.example.json `
          "$env:APPDATA\Claude\claude_desktop_config.json" -Force
```

### 3. 重启 Claude Desktop
完全退出（托盘图标右键 → Quit）再重开。首次会自动拉起 mcp_server.py。

### 4. 验证
- 在 Claude 里直接说：**"调用 pray 的 search_documents，检索 Pray 项目的架构"**
- 或问 **"问 pray：Pray 项目的核心架构是什么"**（整包 ask 模式）
- 设置里若显示 mcpServers → pray 已连接，说明成功

### 5. 排错
- 打开 Claude Desktop 日志（`%APPDATA%\Claude\logs\` 下 mcp*.log）看报错
- 最常见失败：python 路径不对（确认 claude_desktop_config.json 里的
  `command` 是 python.exe **绝对路径**）；API Key 没配（见项目 `.env`，
  Pray 的 key 从 `.env` 自动加载，与 Claude 账号无关）
- 改完配置必须完全退出 Claude Desktop 再重开

### 免装验证（不装 Claude Desktop 时）
用 Python SDK 自检，验证 mcp_server 能在 stdio 下被正常驱动：

```powershell
cd D:\dsh工作区\langgraph-doc-agent
python -X utf8 -c "
import asyncio, sys
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
async def main():
    params = StdioServerParameters(command=sys.executable, args=['-X','utf8', r'mcp_server.py'])
    async with stdio_client(params) as (r, w):
        async with ClientSession(r, w) as s:
            await s.initialize()
            tools = await s.list_tools()
            print('工具数:', len(tools.tools))
asyncio.run(main())"
```

## 二、桌面版：运行 / 打包 exe

### 直接运行（源码模式）
```powershell
pip install -r D:\dsh工作区\langgraph-doc-agent\requirements-desktop.txt
python -X utf8 D:\dsh工作区\langgraph-doc-agent\desktop.py
```
会弹出独立窗口（系统 WebView，非浏览器标签），关窗即退出。

### 打包成 exe
```powershell
cd D:\dsh工作区\langgraph-doc-agent
python -m PyInstaller Pray.spec --noconfirm
```
产物：`dist\Pray\Pray.exe`（双击运行；首次使用注意 Windows SmartScreen 可能提示"更多信息 → 仍要运行"）。

- 默认 spec **排除了 torch/sentence-transformers**：打包 ~200MB，文档检索自动
  回退纯 BM25（够用）；需要语义检索就删掉 Pray.spec 的 excludes 再打（>1GB）
- 无控制台窗口（GUI）；命令行 `Pray.exe --check` 可无窗口自检

### exe 自检
```powershell
dist\Pray\Pray.exe --check
# 输出 [self-check] OK: ... 200 即正常
```

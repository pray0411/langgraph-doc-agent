## 二、安全机制：三个可现场演示的点

### 1. 命令授权改为默认拒绝（体感最明显）

**改造前**：`python xxx.py` 不含黑名单关键词 → "写脚本 → 跑脚本"这条任意代码执行路径**静默通过**。
**改造后**：任何非只读命令都需要你确认，且确认走服务端签发 nonce 的两阶段流程。

现场演示：在 Pray 里说 **"写一个 hello.py 并运行它"**。会看到：

1. 模型调用 `write_file` 落盘
2. 调用 `run_command` 时弹出确认框，**完整展示即将执行的命令**
3. 你点确认后才真正执行；拒绝则中止

这一步在界面上是**看得见的行为差异**——也是本次改动中唯一在前端接入的（前端有 `/api/run/prepare` 与 `/api/confirm` 调用）。

### 2. 审计日志（实测可复现）

`logs/audit.log` 记录 16 类安全事件：`origin_rejected`、`approval_challenge`、`approval_granted`、`approval_consumed`、`approval_expired`、`api_token_autogenerated`、`config_update`、`gateway_probe`、`run_command`、`runterm_prepare/start/stop`、`upload`、`upload_rename`、`uploads_reindex` 等。

实测触发一条（在 PowerShell 里执行）：

```powershell
# 伪造跨站来源发一个写请求 —— 会被拒绝并记入审计
Invoke-WebRequest "http://127.0.0.1:8000/api/mode" -Method POST `
  -Headers @{Origin="http://evil.com"} -Body "mode=deepseek" -UseBasicParsing
# → 403

# 读回审计记录
Invoke-RestMethod "http://127.0.0.1:8000/api/audit?limit=3"
```

实测输出（真实记录）：

```json
{"ts":"2026-09-22T02:06:41","event":"origin_rejected","method":"POST",
 "path":"/api/mode","reason":"来源 evil.com 不是本机已知身份","origin":"http://evil.com"}
```

结构化应用日志在同目录 `logs/app.log`（含凭据脱敏）。

### 3. 来源校验与 Token 强制（平时不可见，出事才体现）

- 带副作用的请求会拿 `Origin` / `Host` 与**服务端自己算出的本地身份集合**比对（不是 `Origin == Host`，那种两侧都能伪造的写法等于没校验）
- 绑定非回环地址（如 `0.0.0.0`）且未配置 `API_TOKEN` 时，**自动生成随机 Token 并打印到控制台**，并以 `api_token_autogenerated` 记入审计

## 四、桌面端与打包

```powershell
dist\Pray\Pray.exe --check
```

实测输出：

```
[self-check] OK: http://127.0.0.1:xxxxx/ 返回 200，页面 72439 字节
[self-check] 版本 1.1.0 | provider=deepseek | API Key=已配置
[self-check] 数据目录 D:\...\dist\Pray
```

含义：页面正常、版本号（读自 `VERSION`）、当前服务商、**API Key 是否被读到**、以及可写数据目录。最后一项是本次修复的重点——打包后数据锚定到 exe 同级目录，不再写进 PyInstaller 临时目录（否则退出即丢）。`.env` 同样从 exe 同级目录读取。

## 五、面试/展示时怎么讲（3 分钟版）

**三条主线**：

1. **安全模型是改造重点**：从"关键词黑名单"到"默认拒绝 + 服务端 nonce 两阶段授权"，并说明为什么——黑名单的缺陷不是漏词，而是判定方向反了，主推的"写脚本→跑脚本"路径恰好绕过它
2. **工程质量可验证**：CI 六组合矩阵（无 Key 无 `.env`）、287 条用例、覆盖率 81% 且缺口逐项披露、变异测试检验"测试能否抓住 bug"
3. **诚实标注边界**：承认 nonce 不构成在场证明、命令执行不是沙箱、覆盖率数字带环境前提（未装 sentence-transformers）

**现场演示哪一条最有效**：让 Pray"写个脚本并运行" → 命令确认弹窗出现（改造前静默执行）；紧接着展示 `logs/audit.log` 里刚写入的记录。一个动作同时体现"授权链路"与"审计可追溯"。

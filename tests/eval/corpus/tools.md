# 工具清单

智能体可以调用的工具分为四类。

**检索类**。**search_documents** 在本地文档知识库中做混合检索，返回带来源的
片段，是文档问答的入口。**web_search** 用于获取实时信息，优先使用博查中文
搜索，未配置密钥时回退 DuckDuckGo。**fetch_url** 只读抓取网页，且严格限制在
白名单域名（github.com 与 api.github.com 等），只允许 GET、不执行任何代码，
重定向逐跳校验白名单，并限制响应体大小。

**文件类**。**write_file** 把内容落盘到可写目录，父目录自动创建，路径逃逸被
拒绝。**read_file** 读取文件，同样受路径边界约束。**edit_file** 对已有文件做
局部替换。**list_files** 列出目录内容。

**执行类**。**run_command** 在可写目录内执行一条命令并返回输出。黑名单拦截
破坏性命令，高危命令需要用户在界面确认后才执行，并设有超时强杀。退出时标准
输出与标准错误**分别返回**，便于判断失败原因出现在哪一路。**open_in_browser**
在浏览器中打开生成好的页面，常用于"生成一个 HTML 小游戏"这类需求。

**记忆与杂项类**。**remember** 与 **forget** 读写全局长期记忆。**get_current_time**
返回当前时间，避免模型凭训练数据里的时间作答。**get_weather** 查询指定城市的
实时天气。

每个工具都自带一组可测面：路径类工具的逃逸与边界、执行类工具的黑名单与确认
门槛、检索类工具的空结果与降级、记忆类工具的长度校验与去重。新增一个工具，
就同时新增了一批断言应该覆盖的行为。
